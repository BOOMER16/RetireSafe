## Lessons recorded during the work

* moto's `TestEventPattern` API handler is a stub (it returns nothing), so the tests use moto's internal rule matcher.
* The parliament linter catches unknown actions but not misspelled global condition keys; a test pins `aws:PrincipalArn`.
* Two harness mistakes sent API calls to real AWS with a dummy key (S3 Control earlier, EC2 here). Both were refused (403 and 401); the harness now routes S3, S3 Control, Route 53, EC2, STS, IAM and SSM to the emulator.
* TCP DNS is blocked in the build sandbox, so very large TXT sets (for example github.com) come back as `lookup_error`. They are never reported as clean.
