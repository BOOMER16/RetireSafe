# Demo kit

Everything needed to demonstrate RetireSafe live and to let a security expert test it. The console starts **empty**. Every result on screen comes from inputs uploaded during the demo, and nothing is pre-loaded.

| File | For |
|---|---|
| [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md) | The presenter: a 7–8 minute walkthrough with exact clicks and what appears |
| [`EXPERT_TESTS.md`](EXPERT_TESTS.md) | The judge or security expert: test cards to break, probe and verify the system |
| [`kit/`](kit) | Upload-ready inputs, one folder per step |
| [`kit/EXPECTED.md`](kit/EXPECTED.md) | What each step produced when run through the API (recorded, not predicted) |
| `build_demo_kit.py` | Rebuilds `kit/`; `--verify` re-runs every scenario and rewrites `EXPECTED.*` |
| `run_steps.py` | Fallback: submits steps 01–04 to the running server over HTTP, as the form does |

## What the inputs are

| Input | Source | Real or constructed |
|---|---|---|
| `plan.json` | `terraform show -json` from Terraform 1.16.4 and hashicorp/aws 6.67.0 (checksums verified), run against the moto AWS emulator | **Real tool output** |
| `route53.json` | `list-resource-record-sets` output from the same environment | **Real tool output** |
| `app.zip` | A small web app plus tools that use the buckets | Constructed for the scenario. It uses the reserved `.example` domain (RFC 2606), so it can never point at real infrastructure. The SRI hashes are real hashes of the files |
| `04_corrected_change/app.zip` | The same app after applying **RetireSafe's own code patch** | Generated by the tool |
| Traffic log | NASA-HTTP, July and August 1995: 3,461,612 real requests, unmodified, attributed to the scenario hosts by fixed path rules (`pilot/scenario.json`) | **Real data** |

The names are deliberately fictitious. Running live checks against someone else's real buckets would be unethical, and the research's own live scan results are kept private for the same reason.

## Before the demo (once, about 10 minutes)

In Anaconda Prompt:

```bat
cd C:\Users\Barenyam\RetireSafe
conda activate retiresafe
git pull origin claude/wonderful-albattani-9aheed
pip install -e "backend[test]"
python scripts\get_data.py
```

`get_data.py` downloads the NASA traffic log (about 37 MB compressed, 373 MB unpacked) and checks its SHA-256. Then start with an empty console:

```bat
del retiresafe.db retiresafe.db-wal retiresafe.db-shm 2>nul
retiresafe serve
```

Open http://127.0.0.1:8080/ and press Ctrl+F5. The review list should be empty.

**Rehearse once.** Steps 02–04 upload the 373 MB log. On the build machine each of those runs took the times listed in `kit/EXPECTED.md`, and a laptop can be slower. If browser upload is slow, run `python demo\run_steps.py 02 03 04` in a second Anaconda Prompt while you talk. It performs the same uploads, and the results appear in the console.
